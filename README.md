# 🧮 Calculadora JavaScript

Projeto web desenvolvido para praticar JavaScript e os fundamentos da lógica de programação por meio da criação de uma calculadora interativa. A aplicação permite realizar operações matemáticas, inserir expressões com parênteses, alternar entre temas claro e escuro e copiar valores para a área de transferência.

## 🛠️ Tecnologias utilizadas
- HTML5 — estrutura da página e dos elementos da calculadora.
- CSS3 — estilização, organização visual, layout com CSS Grid e personalização de temas com variáveis CSS.
- JavaScript — lógica da aplicação, manipulação do DOM, eventos e cálculos matemáticos.
- Clipboard API — cópia de valores para a área de transferência do usuário.

## ✨ Funcionalidades
- Realização de operações matemáticas de adição, subtração, multiplicação e divisão.
- Cálculo de expressões com parênteses.
- Operação de porcentagem.
- Limpeza da expressão digitada.
- Exibição de mensagens de sucesso e erro.
- Cópia do valor exibido para a área de transferência.
- Alternância entre os temas claro e escuro.
- Interface organizada e adaptável a diferentes tamanhos de tela.
- Interpretação de expressões matemáticas sem utilizar a função eval().

## 🧠 Conceitos praticados
- Manipulação do DOM com métodos como getElementById(), querySelector() e querySelectorAll().
- Eventos JavaScript com addEventListener().
- Utilização de funções e parâmetros.
- Manipulação de strings com replace(), split(), slice() e indexOf().
- Expressões regulares para identificação de operadores matemáticos.
- Conversão de strings em números com Number() e parseFloat().
- Recursividade para interpretar e calcular expressões.
- Estruturas condicionais e switch.
- Manipulação de classes CSS com classList.
- Alteração de variáveis CSS com style.setProperty().
- Uso de dataset para controlar o tema da aplicação.
- Utilização da Clipboard API com navigator.clipboard.writeText().
- Tratamento de erros com then() e catch().
- Validação de resultados numéricos com Number.isFinite().
- Controle de versão com Git e publicação de projetos no GitHub.

## 💻 Como executar o projeto
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html em um navegador.
4. Utilize os botões da calculadora para inserir expressões e realizar cálculos.
- Não é necessário instalar dependências ou utilizar um servidor backend.

## 📁 Estrutura do projeto
- index.html — estrutura da calculadora e seus elementos.
- index.css — estilos, layout, cores e temas da interface.
- index.js — lógica dos cálculos, eventos, validações e funcionalidades.
- README.md — documentação do projeto.

## 🎯 Objetivo do projeto

- Este projeto surgiu a partir de uma calculadora desenvolvida durante o curso da OneBitCode, cuja primeira versão utilizava a função eval() para realizar os cálculos. Nesta nova versão, meu objetivo foi recriar a lógica da calculadora sem utilizar essa função, desenvolvendo minha própria forma de interpretar e calcular expressões matemáticas com JavaScript.

- Foi um desafio importante para aprofundar meus conhecimentos em lógica de programação, manipulação de strings, recursividade e resolução de problemas.
